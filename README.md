# 504 error — local version

## Запуск

```bash
npm install
npm start
```

Откройте http://localhost:3000

## Что сейчас работает

- Первый вход показывает первый фрейм.
- При обычном обновлении страницы (F5 / Ctrl+R) счётчик увеличивается ровно на 1.
- Кнопка «обновить страницу» вызывает обычный reload, поэтому тоже увеличивает счётчик ровно на 1.
- После каждого реального reload есть **30% шанс попасть на второй фрейм**.
- Счётчик сохраняется в localStorage браузера.
- Зелёная точка медленно мигает.
- Чат выдвигается снизу с анимацией.
- Онлайн-счётчик и чат работают через WebSocket между открытыми вкладками/пользователями этого сервера.

### Изменить шанс второго фрейма

В `public/app.js` измените:

```js
const FRAME2_CHANCE = 0.30;
```

Например, `0.50` = 50%, `0.10` = 10%.
